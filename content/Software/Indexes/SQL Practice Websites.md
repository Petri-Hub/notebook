# SQL: sites para aprender praticando

Catálogo de plataformas para aprender ou praticar SQL com exercícios executáveis, feedback ou progressão — o mais perto possível do formato do freeCodeCamp. Não é um censo de toda página que aceita SQL: reuni os cursos e practice sites mais úteis que encontrei, e separei os produtos mais novos dos recursos já estabelecidos.

## Onde começar

- **Quero uma trilha curta, grátis e direto no browser:** [[SQLBolt]] começa por fundamentos e intercala explicação com exercícios interativos; depois, use [[SQLZoo]] para mais tutoriais e quizzes.[1][2]
- **Quero uma experiência mais parecida com um curso/projeto:** [[Select Star SQL]] é um livro interativo com queries em um dataset real; [[Codédex]] organiza exercícios em capítulos com progresso e badges.[4][13]
- **Quero SQL de verdade no PostgreSQL:** faça os exercícios do [[PostgreSQL Exercises]]; ele começa em `SELECT` e chega a window functions e recursive queries.[3]
- **Quero treinar para entrevista:** comece pelo plano SQL 50 do [[LeetCode]] e complemente com [[DataLemur]] ou [[StrataScratch]], que se concentram em perguntas de entrevistas de dados.[15][20][21]
- **Quero um formato de jogo:** experimente [[SQL Island]] ou o [[SQL Murder Mystery]]; são atividades com história, não substitutos de um curso completo.[18][19]

## Cursos e trilhas interativas

- [SQLBolt](https://sqlbolt.com/) — lições curtas com exercícios interativos no browser. Um dos melhores pontos de partida se a prioridade é aprender a sintaxe escrevendo queries, sem instalar um banco.[1]
- [SQLZoo](https://sqlzoo.net/) — tutoriais guiados, quizzes e assessments; cobre desde `SELECT` até subqueries, agregações e joins em vários conjuntos de dados.[2]
- [Select Star SQL](https://selectstarsql.com/) — livro interativo gratuito, sem anúncios nem cadastro, com queries sobre um dataset real e capítulos estruturados como pequenos projetos.[4]
- [SQL Easy](https://sql-easy.com/) — trilha de aulas interativas bem focada nos fundamentos, com uma query para escrever e testar em cada passo. Bom complemento rápido para iniciantes.[7]
- [W3Schools SQL](https://www.w3schools.com/sql/) — tutorial de referência com editor “Try it Yourself”; os exercícios misturam preencher lacunas e múltipla escolha, então é menos parecido com escrever soluções inteiras do freeCodeCamp.[5][30]
- [SQL Academy](https://sql-academy.org/en/) — curso por módulos, lições guiadas e exercícios de prática; a própria plataforma separa o curso introdutório de cursos avançados Premium.[6]
- [Codecademy — Learn SQL](https://www.codecademy.com/learn/learn-sql) — curso estruturado com quizzes e projetos práticos; confira no site quais partes e recursos exigem plano pago.[9]
- [DataCamp — Introduction to SQL](https://www.datacamp.com/courses/introduction-to-sql) — mistura vídeos curtos e exercícios interativos, com foco em consultar dados; também oferece uma trilha SQL Fundamentals mais longa.[10][11]
- [Boot.dev — Learn SQL](https://www.boot.dev/courses/learn-sql) — trilha extensa com lições executáveis no browser, cobrindo desde tabelas e CRUD até joins e performance; tem uma pegada mais voltada a desenvolvimento de software.[12]
- [Codédex — SQL](https://www.codedex.io/sql) — curso gamificado dividido em capítulos e exercícios, com progresso, XP e badges; mistura consultas, agregações, DDL e joins.[13]
- [Kaggle Learn — Intro to SQL](https://www.kaggle.com/learn/intro-to-sql) — microcurso em estilo notebook usando SQL no BigQuery, com lições e exercícios para analisar conjuntos de dados maiores.[14]
- [LearningSQL.org](https://learningsql.org/) — curso autodeclarado gratuito com currículo interativo e playground; por ser uma opção independente, vale conferir cobertura e manutenção antes de escolher como trilha principal.[28]
- [SQLHelper](https://sqlhelper.kristinn.eu/) — alternativa de nicho para aprender **T-SQL / SQL Server** por lições e sandbox; útil se esse for o dialeto que você precisa, não como curso de SQL genérico.[29]

## Bancos de exercícios e preparação para entrevistas

- [PostgreSQL Exercises](https://pgexercises.com/) — exercícios com explicações sobre um schema coerente; progride de consultas básicas a agregações, window functions e CTEs recursivas. Ótimo para aprofundar Postgres.[3]
- [SQL Practice](https://www.sql-practice.com/) — terminal e exercícios online para praticar queries em schemas de exemplo; bom complemento para repetir conceitos, não uma trilha didática longa.[8]
- [LeetCode — SQL 50](https://leetcode.com/studyplan/top-sql-50/) — plano curado de 50 problemas de entrevista, agrupados por tópico e dificuldade; alguns recursos do LeetCode podem depender de conta ou Premium.[15]
- [HackerRank SQL](https://www.hackerrank.com/domains/sql) — catálogo de desafios de SQL em níveis diferentes, útil para prática progressiva e exercícios estilo coding challenge.[16]
- [Codewars — SQL kata](https://www.codewars.com/kata/search/sql) — desafios curtos em formato kata, bons para treinar uma query específica depois de aprender o básico.[17]
- [DataLemur](https://datalemur.com/questions) — banco de problemas de SQL e dados inspirado em perguntas de entrevistas, com categorias e dificuldade visíveis.[20]
- [StrataScratch](https://www.stratascratch.com/) — questões de entrevista de Data Science e Analytics, além de mock interviews e projetos; mais indicado para preparação profissional que para aprender do zero.[21]
- [Interview Query — SQL Interview](https://www.interviewquery.com/learning-paths/sql-interview) — caminho de estudo que vai de sintaxe básica a joins, agregações e perguntas comuns de entrevista.[22]
- [DataInterview — Coding Questions](https://www.datainterview.com/coding) — banco amplo de coding questions com trilhas SQL/FAANG; é focado em entrevista e parte do conteúdo pode exigir upgrade.[23]

## Jogos e experiências com narrativa

- [SQL Murder Mystery](https://mystery.knightlab.com/) — investigação curta em SQLite. O próprio site avisa que é mais um exercício de prática com walkthrough para iniciantes do que um curso completo.[18]
- [SQL Island](https://sql-island.informatik.uni-kl.de/) — aventura narrativa em que se progride escrevendo comandos SQL; a interface oferece troca de idioma.[19]
- [QueryQuest](https://queryquest.org/) — candidato para testar com quests, lições curtas, sandbox e feedback; verifique a disponibilidade atual antes de contar com ele como curso principal.[25]
- [SQL Protocol](https://sqlprotocol.com/) — alternativa que combina campanha narrativa, drills cronometrados de entrevista e modo multiplayer; é mais jogo/prática do que curso clássico.[26]
- [SqlInt — SQL Puzzles](https://sqlint.com/sql-puzzles) — histórias em forma de puzzles SQL; a página apresenta capítulos iniciais gratuitos e packs avançados pagos.[27]

## Opções novas para testar

Estes sites também apareceram na busca, mas tratei os detalhes abaixo como descrições dos próprios produtos — não como auditoria independente de qualidade, disponibilidade ou pricing. Vale abrir e testar um desafio antes de investir tempo neles:

- [site-ql](https://site-ql.com/en) — prática interativa com exercícios graduados e PostgreSQL no browser; o site informa que há exercícios gratuitos para começar e mais conteúdo após login.[24]

## Minha rota sugerida

1. **SQLBolt** para aprender a escrever consultas básicas.[1]
2. **SQLZoo** ou **Codédex** para repetir conceitos com mais exercícios e progressão.[2][13]
3. **PostgreSQL Exercises** para ganhar profundidade no dialeto Postgres.[3]
4. **LeetCode SQL 50** ou **DataLemur** se o objetivo for entrevista.[15][20]
5. **Select Star SQL** ou um dataset próprio no Kaggle para praticar investigação de dados com menos scaffolding.[4][14]

Para começar, SQLBolt é minha escolha mais direta.[1]

Para uma trilha interativa mais longa, eu tentaria Codédex ou Boot.dev.[12][13]

Para aprofundar Postgres, PGExercises; para entrevista, LeetCode SQL 50.[3][15]

Os limites de free tier, login e pricing mudam, então confira os termos atuais na própria plataforma.[6][9][12]
